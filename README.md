# 🎬 SubDownloader | Sinhala Subtitle Finder

**SubDownloader** is a sleek, modern, and high-performance web application designed to help users find and download Sinhala subtitles for movies and TV shows across multiple popular sources like **Baiscope**, **Cineru**, **PirateLK**, and **Zoom**.

Built with a focus on speed and user experience, it features a glassmorphic design and real-time search capabilities.

![Logo](logo.png)

## ✨ Features

- 🔍 **Multi-Source Search**: Instantly search for subtitles across 4+ major Sinhala subtitle providers.
- ⚡ **High Performance**: Optimized for fast results and minimal load times.
- 💎 **Premium UI/UX**: Modern glassmorphic interface with smooth animations and interactive elements.
- 📱 **Mobile Responsive**: Perfectly optimized for all screen sizes, from mobile phones to desktops.
- 🛠️ **Direct Download**: Advanced download logic to fetch direct SRT/ZIP links where possible.
- 🎨 **Status Indicators**: Real-time feedback and clear error handling for API connectivity.

## 🚀 Tech Stack

### Frontend
- **HTML5**: Semantic structure.
- **Vanilla CSS3**: Custom design system, CSS variables, and glassmorphic effects.
- **Vanilla JavaScript (ES6+)**: Core application logic and asynchronous API handling.
- **Google Fonts (Outfit)**: Premium typography.

### Backend
- **PHP**: Powering the scraping and API logic.
- **TheCHARITH API**: Optimized for Sinhala subtitle parsing.

## 🛠️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/SubDownloader.git
   cd SubDownloader
   ```

2. **Run the Backend (PHP):**
   The application expects the API to be running on `http://localhost:5000`. You can start a PHP server in the `api/Subtitle-Download-API-main/api` directory:
   ```bash
   cd api/Subtitle-Download-API-main/api
   php -S localhost:5000
   ```

3. **Open the Frontend:**
   Simply open `index.html` in your browser or use a live server (Live Server extension in VS Code).
